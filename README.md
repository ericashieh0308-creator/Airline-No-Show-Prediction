# Airline No-Show Prediction

## Project Overview

This predictive analytics project examines airline passenger no-show behavior using SAS Visual Analytics.

The project compares multiple classification models to identify passengers who are more likely to miss their scheduled flights and evaluates how predictive modeling can support airline operational decision-making.

**Project Type:** Individual Analytics Project  
**Focus:** Predictive Analytics | Classification | Business Analytics  
**Tool:** SAS Visual Analytics  
**Dataset Size:** 10,000 passenger records

---

## Business Problem

Passenger no-shows create operational challenges for airlines, including unused seat capacity, revenue uncertainty, and inefficient resource planning.

The objective of this project is to identify factors associated with passenger no-show behavior and develop a classification model that can help airlines identify higher-risk passengers.

---

## Analytical Approach

The project follows a structured predictive modeling workflow:

1. Data preparation and variable classification
2. Exploratory analysis
3. Stratified train-validation partition
4. Logistic Regression modeling
5. Decision Tree modeling
6. Model comparison
7. Classification threshold evaluation
8. Business interpretation and recommendations

---

## Models

### Logistic Regression
A logistic regression model was developed to estimate passenger no-show probability and identify important predictors.

### Decision Tree
A decision tree model was developed as an alternative classification approach and compared with logistic regression using validation performance.

---

## Model Evaluation

Model performance was evaluated using validation data and classification metrics including:

- ROC analysis
- KS statistic
- Lift
- Event misclassification
- False positive rate
- Classification cutoff analysis

The final model selection considered both predictive performance and practical business implications.

---

## Business Applications

The analysis can support airline decision-making in areas such as:

- Passenger no-show risk identification
- Targeted reminder strategies
- Seat inventory management
- Operational planning
- Customer communication prioritization
